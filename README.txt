RAMZI.exe V2 — NIGHT CITY EDITION

LANCEMENT :
1. Décompresse le ZIP.
2. Ouvre le dossier RAMZI_EXE_V2 dans VS Code.
3. Ouvre Terminal > Nouveau terminal.
4. Installe Flask (une seule fois) :
   py -m pip install flask
5. Lance le site :
   py app.py
6. Ouvre dans ton navigateur :
   http://127.0.0.1:5000

POUR ARRÊTER LE SERVEUR :
Dans le terminal, appuie sur Ctrl + C.

PERSONNALISATION :
Les informations du profil sont dans app.py, dans le dictionnaire PROFILE.
Le design est dans static/style.css.
Les interactions du terminal sont dans static/script.js.

Note : les statistiques affichées sont fictives et servent uniquement au design.
